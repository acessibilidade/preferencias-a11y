Importante: Ferramentas do tipo "overlay tools", NÃO SÃO SOLUÇÕES DE ACESSIBILIDADE!

Essa é uma ferramenta que permite ajustar algumas preferências de leitura de conteúdo de forma simples. Todas as opções presentes nesta (ou em qualquer outra ferramenta deste tipo) já existem em seu sistema operacional por padrão. Apesar de ser útil para algumas pessoas, definitivamente essa não é uma solução de acessibilidade. Implemente-a como item adicional, mas priorize a capacitação de equipes e a construção real de boas experiências em seus projetos.

02 / LEVE PARA O SEU SITE

Uma linha para começar.

Hospede os arquivos da ferramenta e adicione a chamada ao HTML.

  1. Baixe e extraia os arquivos.

    Baixar a ferramenta em ZIP . Extraia o pacote e envie a pasta ferramentas para a raiz do seu site, preservando as subpastas css , js , fonts e img .

  2. Inclua esta linha no <head>. 
    <script src="/ferramentas/js/preferencias.js" defer></script>

    O JavaScript carrega o CSS automaticamente. Se o site estiver em uma subpasta, ajuste o endereço.

  3. Teste nas suas páginas.

    Confira as combinações de preferências, teclado e telas pequenas. O resultado depende do HTML e do CSS do seu site.

Este projeto tem o intuito de demonstrar como implementar uma ferramenta como essa é verdadeiramente simples e ninguém precisa pagar por elas, mas lembre-se que esse tipo de ferramenta não remove barreiras de acessibilidade! Este projeto tem o código aberto, acesse o GitHub (abre em uma nova aba) e use como quiser.

03 / SEM PROMESSAS MILAGROSAS

Ajustar preferências é diferente de resolver problemas REAIS de acessibilidade!

Conheça o site Não acredite em ferramentas milagrosas de acessibilidade (abre em uma nova aba) .

O que você pode ajustar

Tamanho e espaçamento do texto, destaque de controles, fontes e negrito, cores e contraste, zoom, som, animações, vídeos e cor do cursor.

O que precisa de trabalho manual

Semântica, descrições de imagens, nomes de controles, ordem de foco, mensagens de erro e outras barreiras precisam ser tratadas no próprio site.

Preferências são contextuais

O tamanho do texto usa a fonte raiz; o zoom amplia a página. Som e movimento são controlados nos elementos compatíveis.
